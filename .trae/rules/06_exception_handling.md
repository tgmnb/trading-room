# 异常处理机制

## 6.1 Agent 异常

### 6.1.1 Agent 无响应

| 场景 | 处理方式 |
|------|----------|
| Agent 无响应 | 太子调度重试(3次)，超时升级至尚书省 |
| 重试失败 | 升级至尚书省协调 |
| 尚书省也无法解决 | 通知用户手动处理 |

### 6.1.2 Agent 越权

| 场景 | 处理方式 |
|------|----------|
| Agent 越权 | 刑部记录越权事件 |
| 越权严重 | 御史台发出警告 |
| 多次越权 | 冻结该 Agent 权限 |

### 6.1.3 Agent 产出不合格

| 场景 | 处理方式 |
|------|----------|
| 产出不合格 | 门下省封驳 |
| 封驳后重做 | 打回中书省重做 |
| 多次不合格 | 标记为高风险任务 |

## 6.2 流程异常

### 6.2.1 任务卡住

| 场景 | 处理方式 |
|------|----------|
| 任务停滞 > 阈值 | 太子调度自动扫描 |
| 首次停滞 | 触发自动重试 |
| 重试失败 | 升级至门下省协调 |
| 再次失败 | 升级至尚书省 |
| 连续失败 | 自动回滚到稳定节点 |

### 6.2.2 审核超时

| 场景 | 处理方式 |
|------|----------|
| 审核超时 30分钟 | 催办 |
| 审核超时 60分钟 | 升级至尚书省 |
| 尚书省介入 | 指定其他 Agent 审核 |

### 6.2.3 执行偏差

| 场景 | 处理方式 |
|------|----------|
| 检测到执行偏差 | 立即记录 |
| 偏差触发冷静期 | 御史台介入 |
| 严重偏差 | 通知用户确认 |
| 重复偏差 | 生成问责报告 |

## 6.3 数据异常

### 6.3.1 数据缺失

| 场景 | 处理方式 |
|------|----------|
| 必填字段缺失 | 记录缺失字段 |
| 流程 | 暂停，等待补充 |
| 超时未补充 | 标记为异常任务 |

### 6.3.2 数据格式错误

| 场景 | 处理方式 |
|------|----------|
| 格式错误 | 记录错误详情 |
| 严重错误 | 退回修正 |
| 轻微错误 | 自动尝试修复 |

### 6.3.3 数据不一致

| 场景 | 处理方式 |
|------|----------|
| 检测到冲突 | 标记冲突项 |
| 触发 | 发起对账流程 |
| 无法解决 | 升级处理 |

## 6.4 异常处理流程图

```
异常发生
    ↓
判断类型 (Agent/流程/数据)
    ↓
┌─────────────────────────────────────────┐
│ Agent 异常                               │
│   ├─ 无响应 → 重试3次 → 升级           │
│   ├─ 越权 → 记录 → 警告               │
│   └─ 产出不合格 → 封驳 → 打回重做     │
├─────────────────────────────────────────┤
│ 流程异常                                │
│   ├─ 任务卡住 → 重试 → 升级 → 回滚   │
│   ├─ 审核超时 → 催办 → 升级           │
│   └─ 执行偏差 → 记录 → 监察           │
├─────────────────────────────────────────┤
│ 数据异常                                │
│   ├─ 数据缺失 → 记录 → 暂停 → 标记    │
│   ├─ 格式错误 → 记录 → 退回           │
│   └─ 数据不一致 → 标记 → 对账         │
└─────────────────────────────────────────┘
    ↓
记录日志
    ↓
通知相关 Agent
    ↓
继续执行
```

## 6.5 异常恢复策略

| 异常类型 | 恢复策略 |
|----------|----------|
| 临时网络问题 | 自动重试 (最多3次) |
| Agent 崩溃 | 切换到备用 Agent |
| 数据损坏 | 从快照恢复 |
| 流程死锁 | 回滚到上一个稳定状态 |
