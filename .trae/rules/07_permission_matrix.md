## 7.2 禁止越权规则

### 7.2.0 大内总管禁止事项

- 不参与任何朝廷事务（三省六部、御史台、早朝官等）
- 不主动发起任何任务
- 不在没有授权时执行任何操作
- 不向其他任何 agent 发消息
- 不扩大执行范围或自行决定额外操作

### 7.2.1 中书省禁止事项

- 不允许直接下达交易指令
- 不允许确定仓位
- 不允许绕过门下省直接进入执行
- 不允许把主观偏好伪装成客观事实

### 7.2.2 门下省禁止事项

- 不负责重新起草完整研究
- 不负责直接发出交易执行命令

### 7.2.3 户部禁止事项

- 不允许代替用户做最终决策
- 不允许给出超过用户风险承受能力的仓位建议

### 7.2.4 刑部禁止事项

- 不负责安慰用户
- 不负责重新设计交易计划

### 7.2.5 御史台禁止事项

- 不允许空泛骂人
- 不允许对人格做侮辱性评价
- 不允许在无证据情况下指责用户

## 7.3 权限检查规则

### 7.3.1 消息发送前检查

```
发送消息前:
1. 检查发送方是否有权限向接收方发消息
2. 检查发送方是否在职责范围内
3. 检查消息内容是否包含越权内容
4. 记录通信日志
```

### 7.3.2 越权检测

```
越权检测:
1. 监控 Agent 输出内容
2. 检测是否包含职责外的建议
3. 检测是否直接给出交易指令
4. 检测是否绕过审核流程
```

## 7.4 权限级别定义

| 级别 | Agent | 权限范围 |
|------|-------|----------|
| L-1 | 大内总管 | 皇帝授权时最高权限，可操作整个 openclaw 和系统，不参与朝廷事务 |
| L0 | 太子 | 最高权限，可向中书省发消息 |
| L1 | 中书省 | 可向门下省、尚书省发消息 |
| L1 | 门下省 | 可向中书省、尚书省发消息 |
| L1 | 尚书省 | 可向所有六部发消息 |
| L2 | 六部 | 仅可向尚书省回复 |
| L2 | 御史台 | 可向所有 Agent 发消息 |

> **注意**：大内总管（L-1）是特殊级别，只在皇帝授权时激活，权限高于所有朝廷 agent，但不参与任何朝廷事务。
