# 模板规范

## 8.1 通用模板字段

所有输出模板必须包含以下通用字段：

```yaml
通用字段:
  - template_id: 模板唯一标识
  - version: 模板版本
  - created_at: 创建时间
  - author: 创建 Agent
  - tags: 标签

内容字段:
  - 根据具体模板定义
```

## 8.4 模板详细规范

### 8.4.1 事件卡片 (event_card)

```
字段:
  - 事件标题
  - 事件时间
  - 事件类型: 新闻/公告/政策/产业链/突发
  - 事实摘要
  - 直接相关对象
  - 潜在影响路径
  - 市场已知程度: 低/中/高
  - 事件重要性: 低/中/高
  - 证据等级: A/B/C
  - 当前判断: 噪音/进入观察池/可提交候选案
  - 最大不确定点
```

### 8.4.2 技术统计卡 (technical_card)

```
字段:
  - 形态/信号名称
  - 样本定义
  - 历史样本数
  - 样本时间范围
  - 胜率 (主观估计需标注)
  - 盈亏比
  - 最大回撤特征
  - 常见持有周期
  - 当前案例与样本相似点
  - 当前案例与样本差异点
  - 当前最大缺陷
  - 证据等级: A/B/C
  - 当前判断: 可研究/可观察/可提交候选案/证据不足
```

### 8.4.3 候选交易案 (candidate_case)

```
字段:
  - 标的
  - 方向
  - 周期
  - 核心逻辑
  - 预期差
  - 催化剂
  - 支持证据
  - 反对证据
  - 证据等级
  - 失效条件
  - 当前最大疑点
  - 暂定评级
```

### 8.4.4 交易计划书 (trading_plan)

```
字段:
  - 标的
  - 方向
  - 当前优先级
  - 计划类型: 试仓/正式/观察
  - 核心逻辑
  - 为什么它比其他候选更强
  - 进场条件
  - 首次仓位建议
  - 加仓条件
  - 减仓条件
  - 止损条件
  - 止盈/退出条件
  - 失效条件
  - 最大容忍时间
  - 若不触发则如何处理
  - 若出现替代机会则如何处理
  - 门下省放行情况
  - 户部风控情况
```

### 8.4.5 执行偏差记录单 (execution_deviation)

```
字段:
  - 对应计划
  - 实际行为
  - 是否按计划执行: 是/否/部分
  - 偏差类型: 提前/延后/漏做/多做/改规则
  - 偏差说明
  - 偏差后果
  - 是否属于重复违规: 是/否
  - 初步判断: 执行问题/非执行问题/混合问题
```

### 8.4.6 行为监察单 (behavior_supervision)

```
字段:
  - 监察对象: 用户本人
  - 违规/偏差行为
  - 触发场景
  - 对应旧错误标签
  - 本次后果
  - 是否重复错误: 是/否
  - 监察判断: 轻度/中度/严重
  - 问责意见
  - 下次强制要求
```

## 8.5 模板使用规则

1. **强制使用**: 核心决策必须使用 P0/P1 模板
2. **可选使用**: 情报产出可使用 P3 模板
3. **版本管理**: 每次修改需更新版本号
4. **字段校验**: 必须包含所有必填字段
5. **证据等级**: 关键结论必须标注证据等级
