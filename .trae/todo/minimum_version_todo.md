- [ ] **阶段 1 检查**：所有 11 个现有 Agent 的 SOUL.md 都已更新
- [ ] **阶段 2 检查**：御史台的 SOUL.md 已创建并内容完整

## 风险提示

1. **Agent 注册问题**：新增或修改 Agent 后可能需要重新运行 install.sh 来注册
2. **SOUL.md 格式问题**：确保 SOUL.md 格式符合 OpenClaw 要求
3. **状态映射问题**：修改 _ORG_AGENT_MAP 后要确保任务可以正确派发到对应 Agent
4. **测试数据问题**：可能需要清理或重置 data/ 目录下的旧数据

## 回滚计划

如果遇到严重问题，可以回滚：

1. **SOUL.md 回滚**：从 Git 恢复旧版本的 SOUL.md 文件
2. **代码回滚**：从 Git 恢复 dashboard/server.py 的修改
3. **数据重置**：清理 data/ 目录下的运行时数据（保留备份）
