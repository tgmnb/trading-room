# task_workflow（太子）

## 目标
确保太子流程闭环：**接旨立项 → 派发中书 → 接收中书回奏 → 向皇上复命 → 归档**。

## 强制流程
1. 接旨并形成立项单（任务ID、目标、验收标准）。
2. 使用 `sessions_send(sessionKey="agent:zhongshu:main", ...)` 下发正式任务。
3. 等待中书省回奏，不得提前宣告完成。
4. 收到中书回奏后，向皇上形成最终复命（结论+证据+风险）。
5. **仅在复命完成后**进入归档动作。

## 禁止事项
- 禁止未收到中书回奏就结案。
- 禁止未向皇上复命就归档看板。
