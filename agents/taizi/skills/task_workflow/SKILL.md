# task_workflow（太子）

## 目标
确保太子流程闭环：**接旨立项 → 派发中书 → 接收中书回奏 → 主动向皇上复命 → 归档**。

## 强制流程
1. 接旨并形成立项单（任务ID、目标、验收标准）。
2. 使用 `sessions_send(sessionKey="agent:zhongshu:main", ...)` 下发正式任务。
3. 等待中书省回奏，不得提前宣告完成。
4. 收到中书回奏后，**立即主动**向皇上复命（本轮直接输出，不等待皇上追问）。
5. **仅在复命消息已发出后**进入归档动作。

## 禁止事项
- 禁止未收到中书回奏就结案。
- 禁止把“内部已完成”当作“已向皇上回奏”。
- 禁止未向皇上复命就归档看板。
